# AGENTS

## Skills

Load `.agents/skills/laya-mlx/SKILL.md` when the task uses **laya-mlx**: typed decisions on Apple Silicon, email or ticket classification, choice/score/noul questions, multilingual checkpoint routing, shortlisting large label sets, or converting Laya checkpoints to MLX.

Do not load it for upstream-only Laya features (training, RLCD, `laya-serve`, `predict_long`, hooks, CUDA).
